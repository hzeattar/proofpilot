# Hackathon disclosure

ProofPilot was created as a new project for the Agents for Humans Hackathon
during the Submission Period.

- The project uses the Strands Agents SDK in `app/agent.py` for its AWS mode.
- The included local demo workflow is deterministic and clearly labelled as
  non-AI/non-AWS; it exists so judges can run the app without credentials.
- No pre-existing proprietary application code is incorporated.
- AI-assisted development tools may have been used to accelerate drafting and
  implementation. The entrant reviewed and owns the submitted code and assets.
- Any future third-party integration must be used only under its own terms.
